GODX MODS — Pro Starter Demo

Included:
- index.html: public-facing gaming site with search and dynamic cards.
- admin.html: demo admin UI with a local demo password, add/edit/delete cards, file picker, JSON import/export.

IMPORTANT — READ BEFORE PUBLISHING:
1. This is a front-end prototype. It has no real server/database.
2. The demo password is stored in localStorage and is NOT secure. Do not use a real or reused password.
3. Selecting an APK only stores its filename in the browser; it does not upload the file to hosting or create a real download link.
4. Admin changes are stored in the current browser. Public visitors on other devices will not see them automatically.
5. For a real production version, connect server-side authentication, a database, and secure file storage (or use a CMS with protected admin access).
6. Only distribute APKs/files you own or are authorized to share.

Preview:
- Extract the ZIP and open index.html.
- Open admin.html to test the admin demo.

Free static hosting:
- Upload index.html and admin.html to a GitHub repository.
- In Settings → Pages, select Deploy from a branch, choose main and /(root), then Save.
